# Lacrosse Board — legal

The public privacy policy for **Lacrosse Board** (home-screen name *Lax Board*),
the iPhone lacrosse tactics board. Static pages, served by GitHub Pages at
<https://ourpins.github.io/laxboard-legal/>.

| File | Contents |
| --- | --- |
| [`index.html`](index.html) | Top page |
| [`privacy-policy.html`](privacy-policy.html) | プライバシーポリシー（日本語） |
| [`privacy-policy-en.html`](privacy-policy-en.html) | Privacy policy (English) |
| [`styles.css`](styles.css) | The stylesheet from `ourpins-legal`, recoloured |

There is no terms-of-service page. The app has no accounts and nothing is
bought from us directly: the subscription is sold by Apple under Apple's own
standard EULA.

The app source lives in the private repository `ourpins/laxboard`, where
`docs/privacy-policy.md` is the draft these pages were built from. **Change
both together**, and update the date at the top of each page.

Publishing: Settings → Pages → Deploy from a branch → `main` / `/root`.
